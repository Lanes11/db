# Структура проекта

## main.py
Точка входа. Запускает текстовый интерфейс программы.

## tui.py
Модуль с текстовым интерфейсом пользователя.

Отвечает за:
- вывод меню  
- получение данных от пользователя  
- вызов функций работы с базой данных  
- вывод результатов на экран  

## backend/memory.py
Модуль хранения данных.

Содержит:
- класс `Car` (модель автомобиля)  
- структуру хранения баз данных  
- функции для работы с записями:
  - создание  
  - поиск  
  - обновление  
  - удаление  
- функции для создания и переключения баз данных  

---

# Работа с базами данных

- создание новой базы данных  
- переключение между базами данных  
- просмотр списка баз данных  

---

# Работа с записями автомобилей

- добавление новой записи  
- просмотр всех записей  
- поиск записей по фильтру  
- обновление записи по `id`  
- удаление записей по фильтру  

---

# Структура записи автомобиля

Каждая запись содержит:

- `brand` — марка  
- `color` — цвет  
- `horsepower` — мощность  
- `tank_capacity` — объём бака
