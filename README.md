# Структура проекта

## __main__.py

Точка входа. Запускает текстовый интерфейс программы.

## tui.py

Модуль с текстовым интерфейсом пользователя.

Отвечает за:

- вывод меню
- получение данных от пользователя
- вызов функций работы с базой данных
- вывод результатов на экран

## backend/memory.py

Модуль хранения данных.

Содержит:

### Класс `Record`

Представляет одну запись в таблице.

Содержит:

- уникальный идентификатор записи (`id`)
- словарь с данными (`record`)

### Класс `Table`

Представляет таблицу базы данных.

Содержит:

- имя таблицы (`name`)
- список полей (`fields`)
- хранилище записей (`data`)
- автоматический изменяющейся идентификатор записей (`id`)

Реализует операции:

- создание записи (`create_record`)
- поиск записей (`select_record`)
- обновление записи (`update_record`)
- удаление записей (`delete_records`)

### Класс `DataBase`

Управляет таблицами.

Содержит:

- текущую таблицу (`current_table`)
- список всех таблиц (`tables`)

Реализует:

- создание таблицы (`create_table()`)
- переключение между таблицами (`switch_table()`)
- получение текущей таблицы (`get_current_table()`)

## backend/errors.py

Модуль пользовательских исключений.

Содержит:

- `TableAlreadyExist`
- `TableDoesntExist`
- `RecordFieldsIncorrect`
- `FiltersFieldsIncorrect`
- `IncorrectId`
- `IncorrectField`

## tests/test_memory.py

Тестирует бизнес-логику базы данных с помощью unittest.

## tests/test_tui.py

Тестирует текстовый интерфейс по средствам имитации ввода в консоль с использованием unittest.mock.

# Инструкция по запуску проекта

### Установка зависимостей

```bash

```

```bash

```
