# Структура проекта

## __main__.py
Точка входа. Запускает текстовый интерфейс программы.

## tui.py
Модуль с текстовым интерфейсом пользователя.

Отвечает за: 
- вывод меню 
- получение данных от пользователя
- вызов функций работы с базой данных 
- вывод результатов на экран

## backend/memory.py
Модуль хранения данных.

Содержит:

### Класс `Record`
Представляет одну запись в таблице.

Содержит:
- уникальный идентификатор записи (`id`)
- словарь с данными (`record`)

### Класс `Table`
Представляет таблицу базы данных.

Содержит:
- имя таблицы  
- список полей (`fields`)  
- хранилище записей (`data`)  
- автоматический изменяющейся индентификатор записей (`id`)

Реализует операции:
- создание записи (`create_record`)  
- поиск записей (`select_record`)  
- обновление записи (`update_record`)  
- удаление записей (`delete_records`)

### Класс `DataBase`
Управляет таблицами.

Содержит:
- текущую таблицу (`current_table`)  
- список всех таблиц (`tables`)  

Реализует:
- создание таблицы  
- переключение между таблицами  
- получение текущей таблицы

# Работа с таблицами

- создание новой таблицы с пользовательскими полями  
- указание типа поля (`str` или `int`)  
- переключение между таблицами  
- просмотр списка таблиц

# Работа с записями

- добавление новой записи  
- просмотр всех записей  
- поиск записей по фильтру (поддержка частичных фильтров)  
- обновление записи по `id`  
- удаление записей по фильтру
